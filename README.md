# dr-mcp

**MacのDaVinci Resolve無料版を、AIエージェントへのチャット指示で操作するためのMCPサーバー。**

素材の取り込み、使用区間の指定、クリップの配置、基本的な色補正、プレビュー、書き出しまでを一つの作業の流れとして扱います。利用者は編集の意図を伝え、エージェントが対象を確認して操作し、結果を返します。

> **現在は設計・実装計画を整備した段階です。** このリポジトリには、実行可能なMCPサーバー、インストーラー、Mac無料版での実機検証結果はまだありません。以下の機能と体験は実装目標です。

## 目指す使い方

```text
このフォルダの素材でタイムラインを作って。
最初のクリップは冒頭2秒を除いて、次にこのクリップを置いて。
3番目を少し明るくして、彩度は少し落として。
このクリップをもう少し暖かい色にして。
変更前と後を見せて。
今の変更を戻して。
このタイムラインを1080pで書き出して。
```

曖昧な対象が複数ある場合は確認し、特定できる通常の編集は指示に従って進めます。変更前の状態を残し、処理結果と確認できた範囲を返します。

## 対象とする環境

| 項目 | 方針 |
| --- | --- |
| 主対象 | macOS上のDaVinci Resolve無料版 |
| バージョン | 利用者の事前申告を必須にせず、自動検出と機能ごとの確認で判定 |
| 接続 | Resolve内で動く橋渡しスクリプトと、同じMac上のMCPサーバー |
| チャット窓口 | ローカルMCPを実行できるクライアント。画像確認には画像対応モデル・クライアントを使用 |
| 最初の映像対象 | 色空間とフレームレートが明確なSDR素材、単純な映像トラックと関連音声 |
| Studio | 将来の追加接続方式。無料版の動作確認をStudioの成功で代替しない |

すべてのResolveバージョンへの対応を約束するものではありません。接続前はMac上のアプリ情報を調べ、接続後は実際に使えるAPIを確認します。未対応の機能は、理由を示して停止します。

## 接続と利用者の操作

**チャット → エージェント → ローカルMCP → Resolve内の橋渡しスクリプト → Resolve**

無料版向けに、アプリ内のスクリプト経路を利用する設計です。この経路には既存MCPの実装・動作報告がありますが、本プロジェクトではこれから検証します。[既存実装の説明](https://github.com/samuelgursky/davinci-resolve-mcp#free-edition-in-app-bridge)

初回はセットアップとMCP登録を行います。Resolve再起動後には、利用者が橋渡しスクリプトを起動する操作が必要になる場合があります。自動起動は、対象環境で実現性を確認してから追加します。接続中の対応済み編集はチャットから操作することを目標にします。

このリポジトリをChatGPTに見せるだけでMacに接続されるわけではありません。スマートフォンからの利用には、Mac上のエージェントへ指示を届ける別の経路が必要です。

## 基本的な色補正

| 項目 | 初期方式 | 制約 |
| --- | --- | --- |
| 明るさ | RGB信号値への加算 | 物理的な輝度・露出EVではない |
| 彩度 | CDLのSaturation | Resolve画面の数値とは独立した倍率 |
| コントラスト | 信号値0.5を中心にした直線的な補正 | 標準Contrastつまみと同一ではない |
| 暖色／寒色 | 赤・青のゲイン調整 | 色温度の近似。Kelvinや標準Temperature値の指定は初期対象外 |

この4項目をCDLへ変換する方式を最初の検証候補とします。既存の補正に何でもそのまま重ねられるとは扱わず、保存・復帰できる管理対象の補正から実装します。複雑なノード処理、マスク、トラッキング、高度なグレーディングは初期対象に含めません。

## 開発・検証の原則

- 素材ファイルを書き換えず、編集用の別タイムラインやカラーバージョンに変更を保持する。
- 任意コード実行や任意のAPI転送を公開せず、定義済みの操作だけを橋渡しする。
- APIの成功応答、状態の読戻し、画の確認、最終出力の確認を区別する。
- バージョン番号だけで機能を決めず、その環境での観測と検証結果を記録する。
- インストール・テストのコマンドは、実装され実行確認できた時点でREADMEに追加する。
